# Linux Basics

A primer and reference guide for getting started with the Linux terminal and essential command-line tools.

## Overview

This repository contains interactive reference materials covering:
- Terminal navigation and file management
- Essential shell commands and flags
- File permissions, piping, and redirection
- Process management and system basics
