00 Welcome & Introduction

Welcome to Linux Basics — a terminal primer and reference manual published by OSCode IIIT Dharwad. This guide is crafted for students and developers getting started with Linux, terminal environments, and shell workflows.

Ready to begin? Click the Get Started button above or jump straight into any section below to start exploring. Everything is self-contained with practical syntax breakdowns, flags, and actionable examples.
QUICK START IN TERMINAL
# 1. Clone the repository:
$ git clone https://github.com/OSCode-IIITDWD/linux-101.git
$ cd linux-101

# 2. Open the primer in your browser:
$ xdg-open "Linux Basics — A Terminal Primer.html"    # Linux
$ open "Linux Basics — A Terminal Primer.html"        # macOS
$ explorer.exe "Linux Basics — A Terminal Primer.html" # WSL / Windows
